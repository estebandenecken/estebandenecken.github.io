Why it's built this way. The ring exists because time blindness is a perception problem, not a discipline problem — a number you have to read is a number you can ignore. Activate is a 5-minute block for when 25 feels impossible; starting is the expensive step, not continuing. Auto-start removes the decision between blocks, which is where most sessions die. There is no streak and no scoreboard, on purpose: a broken streak is a reason to quit, and this tool has no opinion about yesterday. Completed focus blocks are written to a log you can see under Settings — kept on this device only, pruned after thirty days, and never shown back to you as a number to keep up.
